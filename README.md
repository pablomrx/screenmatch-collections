# Java: Trabalhando com Listas e Coleções de Dados ☕

Repositório com exercícios e desafios desenvolvidos durante o curso **"Java: Trabalhando com Listas e Coleções de Dados"** da Alura.

## 📖 Conteúdos estudados

* Collections Framework
* ArrayList
* List
* Adição e remoção de elementos
* Percorrendo coleções com `for` e `for-each`
* Generics (`ArrayList<T>`)
* Ordenação de listas
* Interface `Comparable`
* Interface `Comparator`
* Sobrescrita do método `toString()`
* Construtores
* Uso de `super()`
* Polimorfismo em coleções
* Pattern Matching com `instanceof`
* Ordenação por múltiplos critérios
* Manipulação de objetos em listas

## 🛠️ Tecnologias utilizadas

* Java 26
* IntelliJ IDEA
* Git
* GitHub

## 📂 Funcionalidades desenvolvidas

* Sistema de gerenciamento de filmes e séries (ScreenMatch)
* Armazenamento de títulos em coleções
* Listagem de elementos utilizando loops
* Exibição personalizada de objetos com `toString()`
* Ordenação alfabética de títulos
* Ordenação por ano de lançamento
* Comparação de objetos com `Comparable`
* Comparação personalizada com `Comparator`
* Aplicação de herança e polimorfismo em listas

## 🎯 Objetivo

Praticar o uso de listas e coleções em Java, aplicando conceitos de Programação Orientada a Objetos para armazenar, manipular e ordenar objetos de forma eficiente.
